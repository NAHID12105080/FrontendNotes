# Web performance metrics:
| Metric | Full Form                   | Measures What?                             | Good Score         |
|--------|-----------------------------|--------------------------------------------|--------------------|
| LCP    | Largest Contentful Paint    | Loading speed of main visible content      | < 2.5s             |
| INP    | Interaction to Next Paint   | Time to respond visually to user input     | < 200ms            |
| CLS    | Cumulative Layout Shift     | Visual stability (avoiding layout shifts)  | < 0.1              |
